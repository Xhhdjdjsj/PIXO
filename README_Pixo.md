# Pixo — SVG Composition Editor

> Профессиональный веб-редактор для извлечения, хранения и комбинирования SVG-компонентов в новые векторные композиции.

Pixo позволяет загружать собственные SVG-иллюстрации, выделять отдельные объекты, сохранять их в библиотеку компонентов и собирать из них новые композиции на холсте. Главная цель — переиспользовать готовые векторные элементы без необходимости рисовать всё с нуля.

## Реализовано в проекте

Текущая версия — локально запускаемый редактор для композиций из SVG и простых объектов, создаваемых инструментами «Прямоугольник», «Эллипс», «Перо» и «Текст». При первом запуске библиотека заполняется 20 компонентами, извлечёнными из четырёх служебных SVG проекта: `public/icons.svg`, `src/assets/react.svg`, `src/assets/vite.svg` и `public/favicon.svg`. Это демонстрационный набор логотипов и их векторных частей, а не 20 самостоятельных иллюстраций. Для соответствия исходному тестовому заданию загрузите вместо него собственные SVG-иллюстрации.

- Импорт нескольких SVG через диалог или перетаскиванием; ограничение — 5 МБ на файл.
- Очистка SVG от скриптов, встроенных обработчиков и внешних ссылок перед показом.
- Просмотр дерева элементов и извлечение узлов вместе с родительскими группами и SVG-определениями.
- Первичный seed служебной библиотеки: 20 компонентов из четырёх имеющихся SVG; seed выполняется один раз и хранится в IndexedDB.
- Добавление исходного файла или извлечённого компонента на холст; перемещение, масштабирование, поворот, дублирование, слои и отмена действий.
- Векторный SVG-экспорт с сохранением исходных цветов, трансформаций и уникализацией внутренних ID повторно используемых компонентов.
- Исходники, компоненты и проекты хранятся в IndexedDB. Настройки интерфейса остаются в localStorage. Данные старой версии мигрируют при запуске.

### Демо-сценарий

1. Запустите приложение командами `npm install` и `npm run dev`.
2. Импортируйте исходные SVG через `Import SVG` или перетащите их в окно.
3. В блоке `Imported files` откройте дерево нужного файла и нажмите `Extract` у элемента или группы.
4. Нажмите на карточку компонента, чтобы добавить её на холст. Повторите для компонентов из трёх разных файлов.
5. Нажмите `Export SVG` и проверьте полученный файл в векторном редакторе.

Извлечение сохраняет разметку выбранного элемента и его предков, верхнеуровневые `defs` и `style`, а также основные наследуемые SVG-атрибуты. Сложные SVG с внешними ссылками намеренно очищаются; поддержка всех возможных CSS-селекторов и зависимостей не гарантируется.

## 1. Концепция и визуальный стиль

Pixo сочетает удобство Figma, точность Photoshop и простоту библиотеки графических ресурсов. Это самостоятельный редактор, а не попытка реализовать все возможности больших дизайн-инструментов.

### Принципы интерфейса

- **Dark by default** — строгая тёмная рабочая среда.
- **Canvas first** — холст занимает центральную часть экрана.
- **Context over clutter** — инструменты появляются там, где они нужны.
- **Non-destructive editing** — исходные файлы не изменяются при создании компонентов.
- **Vector native** — работа с векторными объектами без принудительной растеризации.
- **Keyboard first** — горячие клавиши для частых действий.
- **Local-first MVP** — проекты можно хранить локально, без обязательной регистрации.

### Цветовая система

| Элемент | Цвет |
|---|---|
| Основной фон | `#101114` |
| Панели | `#17181D` |
| Вложенные поверхности | `#1E2027` |
| Границы | `#2B2D35` |
| Основной текст | `#F1F2F5` |
| Вторичный текст | `#9295A1` |
| Акцент | `#8B5CF6` |
| Успешное действие | `#34D399` |
| Ошибка | `#F87171` |

Типографика: Inter или Geist. Иконки: Lucide. Радиусы небольшие, тени минимальные, анимации короткие и ненавязчивые. Интерфейс не должен выглядеть как детская иллюстративная панель или типовой SaaS-шаблон.

## 2. Структура приложения

Приложение состоит из двух основных разделов:

1. **Projects** — управление проектами и исходными файлами.
2. **Editor** — создание и редактирование SVG-композиций.

Дополнительные разделы: **Components**, **Assets** и **Settings**.

### 2.1. Projects — главная страница

Стартовый экран пользователя.

**Верхняя панель:**
- Логотип Pixo.
- Навигация Projects / Components / Assets.
- Поиск по проектам.
- Кнопка `New project`.
- Меню настроек.

**Основная область:**
- Заголовок `Your workspace`.
- Недавно открытые проекты.
- Сетка проектов с миниатюрами.
- Сортировка по названию и дате изменения.
- Поиск и фильтрация.
- Отдельный блок импортированных SVG-файлов.

Карточка проекта содержит превью, название, дату изменения и меню действий.

**Действия с проектом:** открыть, переименовать, создать копию, скачать проект, удалить.

Новая композиция создаётся через `New project`. Пользователь задаёт название и размеры холста либо выбирает стандартный формат.

### 2.2. Editor — рабочее пространство

Редактор занимает весь доступный экран. Интерфейс состоит из верхней панели, левой панели ресурсов, центрального холста, правого инспектора и нижней строки состояния.

#### Верхняя панель — Header

- Логотип Pixo и возврат к проектам.
- Название проекта с возможностью переименования.
- Индикатор сохранения.
- Undo / Redo.
- Импорт SVG и экспорт.
- Дополнительные настройки.

Рекомендуемая высота: 52–56 px.

#### Левая панель — Assets & Components

Ширина около 260 px. Панель можно сворачивать и изменять её ширину.

**Library**
- Поиск по названию.
- Фильтры по типу и категории.
- Сетка миниатюр.
- Добавление компонента на холст.
- Создание категорий.
- Переименование и удаление компонентов.

**Files**
- Список загруженных SVG.
- Миниатюры иллюстраций.
- Название и размеры документа.
- Открытие исходника.
- Просмотр структуры.
- Извлечение элементов.

**Assets**
- Импортированные ресурсы и файлы проекта.

Поддерживаются SVG-файлы, а также сохранение собственных проектов и их повторное открытие.

#### Центральная область — Canvas

Главная рабочая область Pixo.

- Бесконечное рабочее пространство с панорамированием.
- Тёмный фон с ненавязчивой точечной сеткой.
- Масштабирование колёсиком мыши.
- Перемещение холста удержанием Space и перетаскиванием.
- Выделение объектов кликом.
- Перемещение объектов мышью.
- Масштабирование за маркеры выделения.
- Поворот объектов.
- Привязка к сетке и направляющим.
- Отображение размеров и координат.
- Множественное выделение через Shift.
- Выделение рамкой.
- Undo / Redo.

Рабочая область не должна визуально сливаться с панелями. Холст, рамка выделения, направляющие и маркеры трансформации должны иметь чёткие контрастные состояния.

Для MVP допустима ограниченная рабочая область с масштабированием и панорамированием, если полноценный бесконечный холст усложняет разработку.

#### Правая панель — Inspector

Ширина около 280 px. Если объект не выбран, отображаются настройки документа и холста. Если выбран объект — его свойства.

**Transform**
- X и Y.
- Width и Height.
- Rotation.
- Пропорциональное масштабирование.
- Отражение по горизонтали и вертикали.

**Appearance**
- Opacity.
- Fill.
- Stroke.
- Stroke width.

Цветовые свойства доступны только тогда, когда они применимы к выбранному SVG-объекту.

**Object**
- Название.
- Тип элемента.
- Исходная иллюстрация.
- Дублирование и удаление.

Если выделено несколько объектов, панель позволяет изменять общие свойства и трансформировать выделение целиком.

#### Нижняя панель — Status Bar

- Текущий масштаб.
- Кнопки `−` и `+`.
- Подгонка холста под экран.
- Координаты курсора.
- Количество объектов на холсте.
- Индикатор состояния документа.

Панель должна оставаться компактной.

## 3. Контекстное меню правой кнопки мыши

Контекстное меню — одна из ключевых особенностей Pixo. При нажатии правой кнопкой по объекту открывается меню рядом с курсором, не выходя за границы окна.

### Если выбран один объект

- Select.
- Duplicate.
- Copy.
- Cut.
- Paste.
- Rename.
- Save as component.
- Bring to front.
- Bring forward.
- Send backward.
- Send to back.
- Group.
- Ungroup.
- Flip horizontally.
- Flip vertically.
- Delete.

Недоступные команды отображаются неактивными.

### Если выбрано несколько объектов

- Group.
- Duplicate.
- Copy.
- Cut.
- Paste.
- Align.
- Distribute.
- Bring to front.
- Send to back.
- Delete.

### Если нажать на пустой холст

- Paste.
- Select all.
- Deselect.
- Fit canvas.
- Reset zoom.

### Правила поведения

- Контекстное меню не запускает стандартное меню браузера внутри редактора.
- Клик вне меню закрывает его.
- Escape закрывает меню.
- Команды доступны с клавиатуры, если у них есть горячие клавиши.
- Если объект не выделен, нажатие правой кнопкой по нему сначала выбирает объект, затем открывает меню.

## 4. SVG Import — загрузка исходных файлов

Пользователь должен иметь возможность загружать собственные работы без специальной предварительной подготовки.

### Способы импорта

- Кнопка `Import SVG`.
- Перетаскивание файлов в окно.
- Drag-and-drop в область Files.
- Загрузка нескольких SVG за один раз.

### Обработка файла

1. Проверить расширение и содержимое файла.
2. Разобрать SVG через XML/SVG parser.
3. Определить размеры и `viewBox`.
4. Прочитать структуру элементов и групп.
5. Сохранить исходный SVG.
6. Создать превью для библиотеки.
7. Добавить документ в список Files.

Пользователь получает уведомление об успешном импорте либо понятное сообщение об ошибке.

### Безопасность

- Не выполнять JavaScript из загруженных SVG.
- Не разрешать выполнение встроенных обработчиков событий.
- Безопасно обрабатывать внешние ссылки и ресурсы.
- Не вставлять исходный SVG в DOM без проверки и очистки.
- Проверять размер файла и корректность XML.

SVG с неподдерживаемыми конструкциями должен обрабатываться предсказуемо: показывать ошибку или предупреждение, а не ломать редактор.

## 5. SVG Inspector — просмотр структуры

При открытии исходной иллюстрации пользователь изучает её внутреннюю структуру.

В дереве объектов отображаются поддерживаемые элементы:
- `svg`
- `g`
- `path`
- `rect`
- `circle`
- `ellipse`
- `line`
- `polygon`
- `polyline`
- `text` — при поддерживаемой обработке.

Группы можно раскрывать и сворачивать. При выборе элемента в дереве он подсвечивается на предпросмотре. При выборе объекта на холсте соответствующий узел подсвечивается в дереве.

### Извлечение компонентов

Пользователь выбирает объект или логическую группу и нажимает `Save as component`.

Открывается окно:
- Название компонента.
- Категория.
- Предпросмотр.
- Кнопка `Save component`.

После сохранения элемент появляется в Library.

Если объект входит в группу, пользователь может сохранить сам объект или всю группу, когда это возможно без потери визуального результата.

Для MVP достаточно ручного выбора объектов и групп в корректно структурированных SVG. Автоматически разбирать все возможные иллюстрации не требуется.

## 6. Components Library — библиотека компонентов

Отдельное пространство для сохранённых элементов.

### Отображение
- Сетка превью.
- Компактный список.
- Поиск по названию.
- Фильтр по категориям.
- Сортировка по дате добавления и названию.

### Категории по умолчанию
- Characters.
- Objects.
- Nature.
- Decorations.
- Backgrounds.
- Other.

Категории редактируются пользователем.

### Карточка компонента

Содержит превью, название, тип компонента, название исходного файла и меню действий.

### Действия
- Добавить на холст.
- Открыть исходник.
- Переименовать.
- Изменить категорию.
- Дублировать компонент.
- Удалить из библиотеки.

Удаление компонента из библиотеки не должно удалять уже добавленные экземпляры с холста.

### Добавление на холст

Пользователь перетаскивает компонент из библиотеки на холст или дважды кликает по карточке. Новый объект размещается в центре видимой области либо рядом с курсором при перетаскивании.

Каждый экземпляр можно независимо перемещать, масштабировать, поворачивать и удалять.

## 7. Layers — управление слоями

В редакторе есть вкладка `Layers` либо компактный список слоёв внутри панели Inspector.

Каждый слой показывает:
- Название объекта.
- Тип элемента.
- Миниатюру, если доступна.
- Состояние видимости.
- Состояние блокировки.

### Возможности
- Изменение порядка слоёв.
- Переименование.
- Скрытие и отображение.
- Блокировка от случайного изменения.
- Множественное выделение.
- Удаление.
- Группировка и разгруппировка.

Порядок слоёв должен совпадать с фактическим порядком отрисовки SVG. Перемещение слоя должно менять визуальный порядок на холсте и порядок элементов в экспортируемом SVG.

## 8. Composition Tools — сборка композиции

Пользователь создаёт новую композицию, комбинируя компоненты из нескольких исходных иллюстраций.

### Основные операции
- Перемещение.
- Масштабирование.
- Поворот.
- Дублирование.
- Удаление.
- Группировка.
- Изменение порядка слоёв.
- Выравнивание объектов.
- Отражение.
- Изменение прозрачности.

### Выравнивание нескольких объектов
- По левому краю.
- По центру по горизонтали.
- По правому краю.
- По верхнему краю.
- По центру по вертикали.
- По нижнему краю.

Дополнительно можно реализовать равномерное распределение объектов.

### Управление холстом
- Изменение ширины и высоты документа.
- Выбор цвета фона для предпросмотра.
- Подгонка композиции под экран.
- Увеличение и уменьшение масштаба.
- Центрирование композиции.

Цвет фона редактора и фон экспортируемого документа — разные настройки.

**Ограничение:** Pixo не генерирует новые иллюстрации. Все элементы итоговой композиции должны происходить из загруженных SVG.

## 9. Save & Export — сохранение и экспорт

### Сохранение проекта

Проект хранит:
- Название.
- Размеры холста.
- Список объектов.
- Геометрию объектов.
- Порядок слоёв.
- Связи с исходными компонентами.
- Настройки видимости и блокировки.
- Метаданные проекта.

Для MVP рекомендуется IndexedDB для хранения проектов, исходных SVG и библиотеки компонентов непосредственно в браузере.

Сохранение выполняется автоматически после изменений с небольшим debounce, а статус отображается в верхней панели.

Пользователь может экспортировать проект в собственный JSON-формат Pixo и повторно открыть его.

### Экспорт SVG

Кнопка `Export SVG` открывает диалог:
- Имя файла.
- Ширина и высота.
- `viewBox`.
- Цвет фона: прозрачный или заданный.
- Экспорт только видимых объектов.

После подтверждения пользователь скачивает готовый `.svg`.

### Требования к экспорту

- Сохранять векторную структуру.
- Не преобразовывать композицию в PNG.
- Сохранять геометрию, цвета и пропорции.
- Учитывать трансформации объектов.
- Сохранять порядок слоёв.
- Исключать скрытые объекты, если выбран соответствующий режим.
- Обеспечивать открытие результата в популярных векторных редакторах.

При использовании `<defs>`, градиентов, масок, клип-путей и других зависимых ресурсов необходимо сохранять нужные определения и корректно разрешать конфликты идентификаторов.

## 14. Краткое описание архитектуры

### Хранение

Постоянные данные рабочей области хранятся в IndexedDB: база `pixo-workspace`, хранилище `workspace`. В нём раздельно лежат записи `assets` (исходные SVG и компоненты библиотеки), `objects` (объекты текущего холста), `projects`, `active-project-id` и флаг заполнения служебной библиотеки. Параметры интерфейса хранятся в `localStorage`; данные из прежних ключей `localStorage` при загрузке переносятся в IndexedDB.

SVG-ассет описывается полями `id`, `name`, `category`, `width`, `height`, `viewBox`, `markup` и `source`; для связи с исходником используются необязательные `sourceFileId` и `imported`. Объект холста расширяет эту модель: имеет собственный `objectId`, координаты, поворот, прозрачность, видимость и блокировку. Вложенность групп задаётся через `frameId`, `isFrame` и `isGroup`. Проект хранит размеры холста, фон и массив объектов.

### Извлечение

`getSvgStructure` в `src/features/svg-import/SvgStructure.ts` разбирает SVG в дерево узлов. Узел выбирается по пути из индексов дочерних элементов. `extractSvgNode` копирует выбранный элемент и необходимые SVG-обёртки-предки, добавляет определения и стили (`defs`, `style`, маски, фильтры и другие ресурсы), а также переносит основные наследуемые атрибуты. Результат сохраняется в библиотеке как SVG-разметка компонента (`markup`); исходный SVG не изменяется.

При разборе SVG на отдельные объекты границы узлов измеряются через SVG DOM (`getBBox` и `getScreenCTM`) и переводятся в координаты исходного `viewBox`. Преобразование узлов в объекты холста и создание групп выполняются в `src/App.tsx`.

### Повторное использование

Компонент библиотеки можно добавлять на холст многократно. Для каждого добавления создаётся новый `CanvasObject` с уникальным `objectId` и собственными координатами и трансформациями; SVG-разметка компонента используется как содержимое объекта. Импортированный исходник при добавлении может быть разделён на отдельные векторные объекты и группу, связав элементы через `frameId`.

При отображении и экспорте `namespaceSvgIds` в `src/features/export/SvgExporter.ts` переименовывает внутренние SVG `id` и ссылки на них в пределах экземпляра. Это предотвращает конфликты градиентов, масок и других ресурсов, когда на холсте используется несколько SVG с одинаковыми исходными ID.

## 15. Демонстрационный сценарий

1. Пользователь открывает Pixo.
2. Загружает несколько исходных SVG-иллюстраций.
3. Открывает исходную иллюстрацию.
4. Выбирает объект в SVG Inspector.
5. Сохраняет его как компонент.
6. Повторяет операцию для других исходников.
7. Открывает новый проект.
8. Добавляет на холст компоненты минимум из трёх разных исходных иллюстраций.
9. Перемещает, масштабирует и поворачивает элементы.
10. Меняет порядок слоёв.
11. При необходимости использует контекстное меню правой кнопкой мыши.
12. Экспортирует композицию в SVG.
13. Открывает полученный файл в другом векторном редакторе.

Итоговая композиция должна состоять из реальных элементов исходных файлов, а не из сгенерированных заменителей.

## 17. Что не входит в первую версию

Чтобы уложиться в сроки тестового задания, не нужно реализовывать:
- Регистрацию и авторизацию.
- Совместное редактирование.
- Облачную синхронизацию.
- AI-генерацию изображений.
- Полный аналог Figma.
- Сложную анимацию SVG.
- Полноценный редактор узлов Bézier.
- Полную поддержку всех фильтров и эффектов SVG.
- Маркетплейс компонентов.

Главная задача — рабочий инструмент с качественным интерфейсом, корректным извлечением объектов и надёжным SVG-экспортом.

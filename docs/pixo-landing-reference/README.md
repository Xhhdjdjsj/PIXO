# Pixo Landing Page — Motion Update v3

Обновлённая главная страница Pixo: светлый премиальный лендинг, тёмная демонстрация редактора и три зацикленные GIF-анимации.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Для локальной версии не переносите `index.html` отдельно от папки `assets` — там лежат GIF-файлы.

Сборка, npm и внешние библиотеки не нужны.

## Анимации

- Курсор циклично перемещается между шестью точками: импорт файла, выделение объекта, сохранение компонента, перемещение, создание копии и экспорт.
- Индикаторы шагов, подпись и плавающий статус меняются синхронно с действием.
- Визуальный акцент на текущей точке показывает, с каким объектом работает курсор.
- `assets/pixo-move-object.gif` — выделение и перемещение SVG-объекта.
- `assets/pixo-duplicate-object.gif` — создание копии объекта.
- `assets/pixo-build-composition.gif` — перетаскивание компонентов из библиотеки на холст.

В интерфейсе больше нет плашки `Ctrl + D`.

## Интеграция в приложение

CTA-кнопки сейчас ведут на демонстрацию внутри страницы. Для интеграции с настоящим редактором замените ссылки `href="#demo"` на URL редактора (например, `/editor`). Страница не подключает backend и сама по себе не создаёт или не сохраняет пользовательские проекты.
